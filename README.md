# Waresnew Tap

## How do I install these formulae?

`brew install waresnew/tap/<formula>`

Or `brew tap waresnew/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "waresnew/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
